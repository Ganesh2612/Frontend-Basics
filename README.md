# Frontend-Basics

# 💻 Frontend Development Practice: jQuery, JavaScript, HTML5, CSS3

## 📘 Overview

This project is a frontend development exercise focusing on modern web technologies including **JavaScript**, **jQuery**, **HTML5**, **CSS3**, **SASS**, **Bootstrap 4**, and **AJAX**. It demonstrates working knowledge of DOM manipulation, event handling, data binding, form validation, local storage, responsive design, and SVG media content.

---

## 🧱 Main Topics Covered

### 📌 jQuery & JavaScript
- **Selectors & Traversing**
- **Effects** (fade, slide, toggle)
- **Chaining**
- **AJAX Calls** for dynamic data retrieval (with JSON Server)
- **Array Methods**: `grep`, `map`, `filter`, `sort`
- **Event Handling** and Delegation
- **Data Binding & Response Management**
- **Form Validations** using RegEx
- **Local Storage** for client-side persistence

### 🌐 HTML5, CSS3, SASS
- **Semantic HTML5 Elements**
- **CSS3 Styling & Animation**
- **SASS** for advanced styling and nesting
- **Media Queries** for responsive design
- **Bootstrap 4** for grid layout and responsive UI
- **Component-based Project Structure**

---

## 🗂️ Sub-Topics Explored

### 📋 Web Fundamentals
- **DOM Manipulation**
- **Complex CSS Selectors**, **Pseudo-classes**, and **Pseudo-elements**
- **Form Handling** with validations
- **Flexbox** and **Float-based Layouts**

### 🖼️ Media and Visuals
- **Vector Graphics and SVG Drawing**
- **HTML5 Media Content** (video/audio)
- **CSS Shadows** (text-shadow, box-shadow)

### 🔌 Backend Mocking
- **JSON Server** for RESTful API simulation and dynamic CRUD operations

---

## 🧪 Project Features

- ✅ Dynamic UI built using jQuery and JavaScript
- 🧠 Real-time form validation and visual feedback
- 🔍 Search, filter, and sort functionality on data
- 💾 Persistent state using LocalStorage
- 📱 Fully responsive design (Mobile-First) using Bootstrap and Media Queries
- 🎨 Clean, modular structure with SASS-based styling
